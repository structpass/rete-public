# P3a — Desk 協働ジャーニー（チャット／タスク／スレッド／昇格／所有者境界）

> このファイルは cast-and-scenes.md のフェーズ P3 を Given/When/Then に展開したジャーニーです。

> 対象シーン: cast-and-scenes.md §4 の **P3-1〜P3-4**（#入荷検品 でのチャット議論／チャット→タスク昇格・顛末・クローズ／#棚卸差異 のスレッド CRUD／他人の発話編集境界）。
> マルチユーザー化が別セッションで実装済みの前提で、所有者チェック・担当者ドロップダウン・メンション自分宛て絞り込みを **now enforced** として断定（✅）で書く。Backlog 起票連携・昇格元発話の状態遷移など、マルチユーザーとは別理由で未確定なものは ⚠ ＋理由を維持する。
> 権限の正本: rete は 3 軸直交（システム Role × 業務ロール 1 つ × Space membership）。チャネルは親 PROJECT membership で可視解決。業務ロール未割当 = chat/task/file 全 false。システム ADMIN は他人の発話/タスク/添付を編集削除可だが、他人の個人メモ/DM は不可視。
