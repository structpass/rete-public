# rete 業務シナリオ — フェーズ P3b ジャーニー（ファイル・お知らせ・グループ・個人DM）

> このファイルは cast-and-scenes.md のフェーズ P3b を Given/When/Then に展開したジャーニーです。

> 対象シーン: §4 P3-5（ファイル共有＝松本）／P3-6（タスク・チャットへの添付＝小林）／P3-7（社内掲示板お知らせ配信＝中村）／P3-8（グループ間コミュニケーション＝全社安全衛生グループ）／P3-9（個人間 DM）。
> マルチユーザー化実装済みを前提に、**添付 GET の target 所有権チェック・分類(categories)の Space 所有権チェック（cross-Space IDOR 封鎖）** を now enforced としてアサートする。権限の事実: rete は3軸直交（システム Role × 業務ロール1つ × Space membership）。システム ADMIN は chat/task/file 全 CRUD・他人編集可だが**他人の個人メモ/DM は不可視**。業務ロール未割当（加藤）は chat/task/file 全 false。閲覧専用（社外パートナー）は read 中心。

### P3b-01 ファイル共有 — フォルダ作成→版アップロード→ダウンロード

- **登場**: 松本 由美（業務管理部 マスタ管理・事務管理者・file 全 CRUD）
- **システム**: rete files
- **前提(Given)**: 松本は在庫精度改善 PJ の file 権限を持つ。取引先マスタ用フォルダはまだ無い。手元に `北関東フーズ_単価表_2026春.xlsx`（初版）と、単価誤りを直した改訂版（同名）がある。
- **操作(When)**:
  1. files ツリーで `取引先マスタ/単価表` フォルダを新規作成する
  2. 初版 `北関東フーズ_単価表_2026春.xlsx` をアップロードする
  3. 単価を修正した**同名ファイル**を再アップロードする
  4. 一覧から最新版をダウンロードし、続けて版指定で初版もダウンロードする
- **期待結果(Then)**:
  - フォルダがツリーに出現し、サイズ・拡張子制限内のファイルが一覧に表示される
  - 同名再アップロードは**新規行ではなく版として追加**され、版番号が +1 される
  - 既定 DL は最新版・版番号指定で初版もダウンロードできる
  - 対応: S-FILE-01 / S-FILE-02 / S-FILE-03 / S-FILE-08
- **状態**: ⬜ ／ **仕様**: ✅（アサート可能）

### P3b-02 タグ単一付与（全置換）と複数選択の一括付与（追加方式）

- **登場**: 松本 由美（マスタ管理）

- **前提(Given)**: タグマスタに `マスタ` `2026春` `要確認` が存在。`単価表` フォルダ配下に仕入先別の単価表ファイルが5件ある。うち1件には既に `マスタ` タグが付いている。
- **操作(When)**:
  1. `マスタ` が付いた1件に対し、単一タグ操作で `2026春` を設定する（単一付与＝全置換系）
  2. 一覧で5件すべてを複数選択し、`要確認` を一括付与する
- **期待結果(Then)**:
  - 単一付与は指定タグで**置き換え**る挙動（既存タグ集合をその指定で上書き）
  - 複数選択の一括付与は**追加方式**で、既存タグを消さずに `要確認` を足す（5件すべてが `要確認` を持つ）
  - 対応: S-FILE-05
- **状態**: ⬜ ／ **仕様**: ✅（アサート可能）

### P3b-05 非システム ADMIN の全体設定改変を 403（DoS 封鎖）

- **登場**: 松本 由美（事務管理者・file 全 CRUD だが**システム MEMBER**）
- **システム**: rete files / settings
- **前提(Given)**: 松本は file の CRUD は持つが、テナント全体の files 設定（アップロード上限・拡張子許可リスト等）を変える権限は無い（それはシステム ADMIN の管理系）。
- **操作(When)**: 松本が `PATCH /files/settings` を直接叩いてアップロード上限を変更しようとする
- **期待結果(Then)**:
  - 403 で拒否される。file CRUD 権限（業務ロール）と全体設定変更権（システム ADMIN）は**直交**し、後者は MEMBER に開かない（非 ADMIN の全体設定改変＝全社 DoS を封鎖）
  - UI 上に settings 改変の導線が出ない
  - 対応: S-FILE-10
- **状態**: ⬜ ／ **仕様**: ✅（アサート可能）
