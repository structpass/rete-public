# P3c — パートナー・顧客との連携チャネル（社外ゲスト・スコープ境界）ジャーニー

> このファイルは cast-and-scenes.md のフェーズ P3（P3-10／P3-11／P3-12）を Given/When/Then に展開したジャーニーです。

社外ゲスト（仕入先・運送・顧客）が rete の**連携チャネルにだけ**参加し、社内担当（小林・渡辺）と納期調整・欠品連絡・受発注・配車をやり取りする世界を固定する。
中核は **マルチユーザー化が enforced された前提でのスコープ越境遮断**：高木（北関東フーズ）は `#北関東フーズ連携` のみ membership を持ち、他チャネル／プロジェクト／組織は一覧に出ず、URL を直叩きしても 403。閲覧専用ロールゆえ発話はできるが管理操作（分類 CRUD・設定・他人の編集削除）は不可。誤投稿の削除→再連絡という業務リカバリも併せて確認する。

権限モデル（前提・3軸直交）：システム Role × 業務ロール（1つ）× Space membership。

- システム ADMIN（高橋）= chat/task/file 全 CRUD・他人発話の編集可。ただし第三者の個人メモ／DM は不可視。
- 業務ロール未割当（加藤）= chat/task/file 全 false。
- 閲覧専用ロール（社外パートナー：高木・森田・大野・藤田・三田）= read 中心。連携チャネル参加で発話はするが管理操作は不可。
- チャネルの可視性は**親 PROJECT の membership** で解決する。
- 退職ロック = `Account.isActive=false`（認証即 401）。
